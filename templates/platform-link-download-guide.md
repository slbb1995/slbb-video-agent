# 平台链接下载指南

如果你给的是抖音 / 小红书 / 快手 / B 站等平台链接，不能直接进入 AI 长剧 S1。

请先下载成本地 mp4 文件。

可选第三方工具：

```text
https://sv.bugpk.com/
```

操作方式：

1. 复制平台视频分享链接。
2. 打开 `https://sv.bugpk.com/`。
3. 粘贴链接并解析。
4. 下载视频文件。
5. 把下载后的本地视频路径交给 Codex。
6. 再运行 `slbb-video-source` 和 `slbb-video-ingest`。

注意：
- 第三方解析网站可能失效、限流或解析失败。
- 失败时可以改用录屏、平台自带保存、截图+字幕材料。
- 请只处理你有权学习、分析或二创的素材。
