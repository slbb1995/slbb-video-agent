# Security Policy

## Supported version

Security fixes are applied to the latest commit on `main`.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting form:

https://github.com/slbb1995/slbb-video-agent/security/advisories/new

Include the affected file or command, reproduction steps, expected impact, and any suggested mitigation. Reports will be reviewed before public disclosure.
