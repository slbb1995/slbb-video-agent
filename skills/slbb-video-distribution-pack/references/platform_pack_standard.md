# S7 平台分发包标准

## 总规则

- 第一版只做手动发布材料，不自动发布。
- 输出必须明确：未发布、手动发布、不自动发布。
- 不承诺平台算法效果，不编造账号权限、流量、审核结果。
- 不改写剧情事实，不把普通故事包装成虚假事件。
- 如果 S5/S6 有阻塞问题，分发包要标记“暂不建议发布”。

## 通用分发包字段

- 成片名称或编号
- 最终视频路径或草稿链接
- 目标平台
- 目标受众
- 核心冲突
- 一句话看点
- 标题候选，至少 5 个
- 简介或看点文案
- 封面建议
- 发布时间建议
- 风险与人工确认（写入 `publish_checklist.md` 或 `_meta`）
- 发布状态：未发布 / 手动发布 / 不自动发布

## 抖音

适合更短、更直接的冲突表达。

必须包含：

- 标题：1-3 个强钩子标题
- 正文：1-2 行，直接给冲突和看点
- 话题：3-8 个
- 封面：一句能在移动端看清的封面字
- 发布时间建议
- 检查备注写入 `publish_checklist.md` 或 `_meta`，不要混进平台文案

## 视频号

适合更像真实转述和关系冲突的表达。

必须包含：

- 标题：1-3 个直接标题
- 正文：可以稍微完整，强调人物关系、选择、后果
- 评论引导：一句自然的问题或观点
- 话题：2-5 个
- 封面建议
- 发布时间建议
- 检查备注写入 `publish_checklist.md` 或 `_meta`，不要混进平台文案

## 小红书

适合笔记感标题和分段正文。

必须包含：

- 标题：3-5 个笔记感标题
- 正文：分段写清故事冲突、反转、情绪点
- 标签：5-10 个
- 封面字：短、清楚、适合截图封面
- 发布时间建议
- 检查备注写入 `publish_checklist.md` 或 `_meta`，不要混进平台文案

## 不适合进入发布的情况

- S5 结论是 reject，且没有新的修正后视频。
- S6 修正项没有完成或没有用户确认。
- 最终视频路径缺失。
- 版权、肖像、敏感内容、平台规则存在明显疑问但无人确认。
- 文案为了吸引点击改写了剧情事实。
